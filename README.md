## Chapter 17 – Challenge 3: Ternary Conditional Operator

For this challenge, I explored how to add support for the ternary conditional operator (`?:`) in Lox.

The solution includes:

- Adding new tokens for `?` and `:`.
- Introducing a conditional precedence level.
- Creating a parsing function for conditional expressions.
- Updating the Pratt parser's rule table.
- Demonstrating how nested conditional expressions are parsed.
